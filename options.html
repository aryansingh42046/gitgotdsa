GitGotDSA

Every accepted solution, committed for you.

Solve on LeetCode, GeeksforGeeks, or Codeforces. GitGotDSA commits the code, the problem statement, and your runtime stats to your own GitHub repo.

Setup

  1. Open the GitGotDSA popup from the toolbar and click Connect GitHub.
  2. Authorize GitHub in the browser window that opens.
  3. Pick an existing repository, or create a new one right there.
  4. Solve a problem — the push happens on “Accepted”.

What gets committed

problem-name/problem-name.py with your accepted code, plus a README.md containing the problem statement, difficulty, topics, and your runtime and memory results.
